# 0. Порядок работы

## На действующей тестовой Ubuntu

Сначала только диагностика:

```bash
cd /srv/Server-setings
python3 scripts/serverctl.py doctor
python3 scripts/serverctl.py repair-public-caddy
```

Не запускайте установщик на существующем сервере: он намеренно останавливается, если обнаружена БД 1Panel. Состояние конкретной машины: `snapshots/2026-10-19/test-ubuntu.json`. Действующая конфигурация описана в `docs/01-ЭТАЛОН-ТЕСТОВОГО-СЕРВЕРА.md`.

## На чистой Ubuntu 24.04 LTS

1. Обеспечьте консоль/VNC/IPMI у VPS или физический доступ, рабочий SSH и интернет. Проверьте, что нет других сайтов на 80/443 и выбранный порт панели свободен.
2. Клонируйте приватный репозиторий средствами вашего GitHub-аккаунта (GitHub CLI или заранее настроенный SSH-ключ с доступом). Не копируйте приватные токены в командную строку.
3. Для домашнего сервера со статическим внешним IP:

```bash
cd Server-setings
python3 scripts/serverctl.py plan --profile home-static
sudo bash install.sh --profile home-static --apply
```

Для сервера с динамическим IP используйте `--profile home-dynamic`; для VPS — `--profile vps`. **На VPS, если не вошли по SSH, добавьте `--admin-cidr` со своим доверенным публичным IP в формате `/32`; без него UFW не включится.**

4. Скрипт устанавливает базовый Docker, Tailscale и 1Panel с проверкой SHA256 официального архива. Пароль панели и защищённый вход формируются случайно и сохраняются в root-only-файле, но не в Git.
5. Подключите tailnet (`sudo tailscale up`) и проверьте возможность удалённого входа. Прежде чем править SSH, убедитесь, что есть второй канал восстановления.
6. Создайте API-ключ в 1Panel с IP-allowlist. На сервере: `sudo install -d -m 700 /var/lib/server-settings`; затем сохраните ключ в `/var/lib/server-settings/1panel-api.key` с правами `0600`, не выводя его в историю shell.
7. Прочитайте `docs/04-ПУБЛИКАЦИЯ-САЙТОВ.md`, установите OpenResty через `scripts/panelctl.py`, создайте сайт в 1Panel и настройте подтверждённый HTTPS/автопродление. Скрипт намеренно не выпускает фиктивный публичный сертификат и не создаёт пустую ASA Lab.
8. Проверьте `python3 scripts/panelctl.py inspect` и `python3 scripts/serverctl.py doctor`.

**Критерий приёмки:** после reboot сайт доступен, 1Panel показывает сайт и сертификат, сертификат продлевается, нет публичных портов администрирования, штатные Docker-тома сохранены, а аварийный SSH доступен.
