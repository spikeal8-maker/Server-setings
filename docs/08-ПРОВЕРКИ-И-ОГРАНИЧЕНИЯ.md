## Минимальные команды диагностики

```bash
python3 scripts/serverctl.py doctor
python3 scripts/serverctl.py repair-public-caddy
sudo python3 scripts/panelctl.py inspect
sudo systemctl status 1panel-core 1panel-agent tailscaled docker --no-pager
sudo ss -lntp
sudo ufw status numbered
sudo docker ps
```

При подготовке PR: `python3 -m unittest discover -s tests -v`, `bash -n install.sh scripts/*.sh`, `python3 -m compileall -q scripts`, проверка `git diff --check`, скан на секреты. GitHub CI проверяет эти операции, но **не разворачивает живую Ubuntu**.
