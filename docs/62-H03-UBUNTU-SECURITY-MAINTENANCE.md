# ASA LAB H03 — обновление безопасности Ubuntu через 1Panel

Статус: пилотная установка на `admins-MS-7D22` (Ubuntu 24.04.4 LTS).
Рабочие DNS, TLS, OpenResty, ASA LAB PostgreSQL/MinIO, IZO ASA и школьные туннели не меняются при подключении меню.

## Вход владельца

Открыть `https://1panel.asa-lab.ru` → **Терминал → Быстрые команды → Ubuntu · Обновления и безопасность**.

| Команда | Действие |
| --- | --- |
| Состояние Ubuntu и безопасности | Показывает ядро, reboot-required, число кандидатов Security, сервисы и последнюю копию |
| Обновить каталог пакетов Ubuntu | Выполняет только `apt-get update`, **не** устанавливает пакеты |
| План полного обновления Ubuntu | Только `apt-get -s upgrade`; отдельно показывает критические Docker/сеть/ядро |
| Проверить исправления безопасности | Безопасный `unattended-upgrade --dry-run` |
| Установить исправления безопасности | Только разрешённые `noble-security` через `unattended-upgrade`; опасные пакеты, неподтверждённые копии и отсутствие ручного «ДА» блокируют действие |

Команды не выполняют `dist-upgrade`, `do-release-upgrade`, `reboot`, `apt autoremove` или обновление прошивки.
Принудительная перезагрузка запрещена политикой `/etc/apt/apt.conf.d/52asa-h03-security-no-reboot`.

## Требования для опасной операции

До установки security-пакетов оператор проверяет:
1. Привязку hostname/root и Ubuntu 24.04, системный lock, отсутствие чужой параллельной операции.
2. Свежую подтверждённую полную облачную копию ASA LAB (до 26 часов) с совпадением точного SHA/схемы/instanceId.
3. Изолированное восстановление свежей локальной базы и копии объектов по принятой квитанции root-only.
4. Работу Docker, 1Panel Core/Agent, Tailscale и MCP ASA LAB.
5. Список пакетов из доверенного Ubuntu Security origin, без критических компонентов ядра/сети/Docker/SSH/libc/systemd.
6. Интерактивное подтверждение «ДА». При ошибках отключается установка, не ослабляется TLS, не удаляются базы и тома.

Механизм автоматического `unattended-upgrades` уже установлен в Ubuntu. Этот набор команд не включает неконтролируемый автоматический `apt upgrade` по сторонним репозиториям Docker/NodeSource/Tailscale.

## Установка

На H03 через root, из проверенного checkout `spikeal8-maker/Server-setings`:

```sh
python3 -B scripts/install-h03-ubuntu-menu.py
python3 -B scripts/install-h03-ubuntu-menu.py --apply
```

Установщик применяет только новую группу команд, отдельный исполнитель под `/usr/local/libexec/asa-h03` и запрет auto-reboot; до изменений сохраняет root-only снимок меню. Повторный запуск идемпотентен при совпадении содержимого, чужие команды не меняет.

Рабочая версия 1Panel отдельно обслуживается через официальное обновление в панели. На H03 выявлена независимая проблема TLS/CDN обновления v2.3.2 → v2.5.1: `Server-setings#112`; она не решается обновлением Ubuntu.

## Запреты и приёмка

- Запрещены произвольная перезапись DNS, hosts, сетевых unit, `docker compose down -v`, `docker system prune`, сброс 1Panel и установка Ubuntu 26.04.
- Перед reboot требуются внешний путь к IPMI/консоли, завершённая копия и проверка восстановления, контролируемая проверка Docker/OpenResty/FRP/1Panel после старта.
- В приёмке проверяется точное сохранение других 17 быстрых команд ASA LAB; HTTPS 200 для `test.asa-lab.ru` и `1panel.asa-lab.ru`, 6/6 healthy.
- Следующие полноценные обновления Docker, containerd, Tailscale, NetworkManager, Netplan, ядра и libc выполняются отдельными последовательными этапами с наблюдением и возможностью возврата.
