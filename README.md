# Server-setings

Русскоязычный репозиторий эталонных настроек серверов Ubuntu, 1Panel, OpenResty, HTTPS, Tailscale и безопасного администрирования.

**Статус:** репозиторий инициализирован. Проверенные сценарии установки, документация и тесты публикуются через отдельную рабочую ветку и pull request. До проверки не следует использовать этот коммит как готовый установщик.

**Безопасность:** в Git не должны попадать открытые API-ключи, SSH-пароли, приватные ключи TLS, базы данных или резервные копии с персональными данными.
