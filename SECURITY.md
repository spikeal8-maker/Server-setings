# Модель безопасности

Это **публичный** GitHub-репозиторий (проверено по metadata GitHub 2026-10-22); он не предназначен для хранения секретов. Секреты не хранить в открытом виде ни в коде, ни в коммитах, ни в Git LFS, ни в Issues, ни в CI. Git хранит историю даже после удаления файла. После утечки ключ следует отзывать, а не только удалять файл.

## Что здесь допустимо

Порты, версии, IP тестового оборудования, шаблоны, правила безопасности, SHA256 образов, списки проверок и архивные метаданные без персональных данных.

## Где хранятся реальные секреты

* `/var/lib/server-settings/1panel-admin.env` — учётные данные, созданные установщиком, root 0600.
* `/var/lib/server-settings/1panel-api.key` — ключ 1Panel для сценариев с API, root 0600, создаётся **отдельно владельцем** через 1Panel.
* `/etc/server-settings/mcp.env` — ключ доступа к локальному MCP + Bearer, root 0600.
* `/etc/server-settings/age-recipients.txt` — только **публичные** адреса age. Приватные identity остаются вне сервера резервных копий.
* `/srv/asa-lab/.env`, Docker environment — секреты приложения; не переписываются этим репозиторием.

## Доступ

* SSH и порт 1Panel — только из разрешённой LAN, администраторского IP или через Tailscale.
* Порт 39443 для MCP — только `127.0.0.1`, без NAT/proxy и публичного IPv4.
* Публичные 80/443 — только если действительно нужен опубликованный сайт.
* 5432 PostgreSQL, 9000 MinIO, API Docker ASA Lab — не публиковать.
* Настройки DNS, маршрутизации и SSH hardening не менять до подтверждения аварийного доступа.
* 1Panel через HTTP в LAN не шифрует логин от прослушивания локальной сети. Для удалённого доступа используйте SSH-туннель / защищённый канал Tailscale или TLS; не открывайте 19192 в WAN.

## Нюансы

Docker с `ports` на `0.0.0.0` способен обойти предполагаемую защиту UFW. Каждый сервис должен явно публиковать только нужные интерфейсы, а API/БД — внутренние сети. MCP `readonly` ограничивает инструменты MCP, **не** превращает сам 1Panel API-ключ в ключ только для чтения. Запуск непроверенного MCP/скрипта с этим ключом даёт административный риск.
